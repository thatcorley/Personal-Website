# Personal Website

My personal site has been made to display any information about my online persona

**Live Demo:** [thatcorley.github.io/Personal-Website](https://thatcorley.github.io/Personal-Website/)

## About

The website is built with HTML, CSS, and a small bit of JavaScript. It's got a home page with a bit about me and some fun facts, a projects page that is in progress, and a links page for all of my socials and other relevant links. Plus an animated fog background I found by [Vanta.js](https://www.vantajs.com/)

## Pages

- `index.html` - Home page that has a small intro, fun facts, interests, and what I'm currently up to
- `projects.html` - Things I've made
- `links.html` - Links to my profiles/socials

## Tech stack

- HTML, CSS, JavaScript
- Hosted on GitHub Pages

## Running locally

I doubt you'll want this but might as well state it anyway. Just clone the repo and open `index.html` or other files in your browser. Don't need a web server for this one.

## Deployment

The site auto-deploys to GitHub Pages via Actions whenever changes are pushed.
